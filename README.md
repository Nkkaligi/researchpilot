# Research Paper to Diagram Agent

An AI-powered application that transforms research papers into meaningful, structured, and editable diagrams. It processes PDF documents, analyzes their content using LLMs, identifies suitable diagram types, and generates Draw.io diagrams with automated review and refinement.

**Key features**
- PDF text extraction and chunk-based processing
- AI-powered research paper analysis and synthesis
- Automatic diagram type selection
- Multi-type diagram generation (architecture, workflow, sequence, ERD, and more)
- Diagram validation and AI-based review
- Cloud architecture icon support (AWS, Azure, and GCP)
- Editable Draw.io output
- Interactive interface powered by Gradio

**Tech stack:** Python · Gradio · OpenAI API · PyMuPDF · Draw.io XML
